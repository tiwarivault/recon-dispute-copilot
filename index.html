Design principle: split brain

All money math and transaction matching are deterministic (exact keys, tolerances). Root causes are shown as "Likely … (confirm)" with a confidence score — they are heuristics, not asserted facts. There is no AI in this build; the chargeback copilot uses rule-based classification + templates. Consequential actions stay with a human.

Reconciliation engine

  • Robust CSV parsing (quoted fields, commas inside values, ₹ and 1,00,000 separators).
  • Multi-key matching — tries every reference column common to both files.
  • Classifies: Matched · Timing · Amount mismatch · Fee mismatch · Missing in settlement · Unmatched settlement · Duplicate.
  • Heuristics flagged for confirmation: net-of-fee settlement, ~18% GST on fee, T+n cycle.
  • Large files: parsing + matching run in a Web Worker so the UI never freezes; only exceptions are rendered (capped), full breaks are downloadable. Use the stress-test buttons to benchmark on your machine.
⚠ Honest limits of THIS build: it is a browser prototype — no backend, database, auth, audit log or scheduled ingestion. Reason codes/evidence are illustrative; verify against live Visa/Mastercard/RuPay/NPCI-UPI manuals. Not an official NPCI/network rule. For enterprise use it needs a backend + persistence + access controls (see roadmap).
